# فونت‌ساز متن

سایت فونت‌ساز با تم سرمه‌ای و آبی نئونی.

- **سبک‌های قابل کپی:** ۷۰ سبک یونیکد (بولد، دست‌نویس، گوتیک، قاب‌ها، خط‌دار، کشیده‌ی فارسی و ...) که با یه لمس کپی میشن.
- **فونت‌های واقعی:** بیش از ۱۰۰ فونت فارسی و انگلیسی از Google Fonts با فیلتر زبان و رنگ نئون.
- **دانلود عکس شفاف:** خروجی PNG بدون پس‌زمینه برای برنامه‌های ادیت.

## فایل‌ها

| فایل | کار |
| --- | --- |
| `index.html` | کل سایت (طراحی، کد و لیست فونت‌ها) |
| `server.js` | سرور ساده‌ی Node بدون نیاز به نصب پکیج |
| `README.md` | همین راهنما |

## اجرا

با سرور Node:

```bash
node server.js
```

بعد `http://localhost:3000` رو باز کن. برای عوض کردن پورت:

```bash
PORT=8080 node server.js
```

بدون سرور هم می‌تونی `index.html` رو مستقیم با مرورگر باز کنی.

## نکته‌ها

- فونت‌ها از Google Fonts میان، پس اینترنت لازمه.
- سبک‌های قابل کپی فایل فونت نیستن و حروف یونیکد هستن. بعضی بازی‌ها و اپ‌ها بعضی نمادها رو نشون نمیدن.
- برای گذاشتن روی هاست، `index.html` رو روی هر هاست استاتیک آپلود کن یا `server.js` رو روی هاست Node اجرا کن.
